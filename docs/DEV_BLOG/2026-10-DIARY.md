## 2026-10-21 - Challenge maps from the harness

- **fix(cmdline):** `-file <map>` was registered inside the `RTS_DEBUG` block of the command-line table (with its parser function), so a
  release build ignored it and showed the main menu. Both moved out. Note the argument is the short form `Maps\<Name>.map`; the parser
  expands it to `Maps\<Name>\<Name>.map`, so a full path gets the folder doubled and loads nothing.
- **feat(harness):** `-file <map> -soloAutopilot "sec:level,..." [-soloMinutes N] [-soloTemplate Faction...]` runs a single-player map
  headless (faster than real time) with the human on Autopilot, then prints `AISKIRMISH_RESULT` stats. For a Challenge map it first
  does what the Challenge menu does (`setupChallengeForMap` in `ChallengeMenu.cpp`: campaign, `TheChallengeGameInfo`, human slot);
  without that the map's `ThePlayer` owns nothing and its script `Lose_END_Start_China` (condition `PLAYER_ALL_DESTROYED`) ends the
  game on frame 0. Found with gdb breakpoints on `ScriptEngine::startEndGameTimer` and a count of objects per player.
- **gotcha:** the headless loop does not deliver a message appended to `TheMessageStream` (it vanishes in `propagateMessages`), so the
  solo schedule puts `MSG_SET_AUTOPILOT` straight on `TheCommandList`, like the replay simulation does.
- **feat(autopilot):** Explore also targets capturable buildings owned by the civilian player (Challenge maps give their tech buildings to
  `PlyrCivilian`, whose relationship is neutral; only the game's own neutral player counted before). Death Valley numbers are identical;
  Challenge: Laser General map $15k -> $38k earned as China Infantry General. The "nothing to capture" trace now lists who owns the rest.
- **fix(harness):** GC_Nuke / GC_Stealth / GC_ChinaBoss ended in seconds: the Challenge setup only looked at each campaign's first mission. All nine maps run now.
- **feat(autopilot):** `AutopilotSnapshot` (read-only JSON of what the player can see, fog respected) and `-soloSnapshot`; design of the directive layer in `AUTOPILOT_DIRECTIVES.md`. Gotcha: `AsciiString::format` truncates at ~2 KB, concatenate long strings.
- **feat(autopilot):** activity feed (`AutopilotLog::feed`): plain sentences about what Autopilot does, on the in-game message line and as `AUTOPILOT: ...` on the console, for the local player only.
- **fix(autopilot):** the civilian-owned targets made explorers re-scout unreachable tech buildings (173 times in one run) and cost Death Valley income 11%. Three scouting tries per building and a preference for oil derricks / refineries bring it back to -5%. Lesson: `autopilot_scenarios.py` runs the installed binary, so an earlier "identical" check was a stale-binary false positive; always `cp` the build first and bisect by toggling code.
- **feat(autopilot):** module toggles: a level is a starting set of `AM_*` modules and `MSG_SET_AUTOPILOT` can carry an exact set (Ctrl+Shift+D flips Defense Units). New Defense Units module (standing tank / tank hunter / rifleman force). Honest result: no gain against Hard (13.0 vs 13.0 min; spending harder was worse, 11.0), so it stays off by default. Linux + Windows sync with the set changing mid-match: in sync.
- **feat(autopilot):** level 6 Fortress = Wallet + Explore, found by layering with the module mask. Vs a Hard AI on Death Valley: 10/12 survive 16 min (Wallet alone 5/12), income $87k vs $30k; 7 of 9 Challenge maps reach a 15-minute cap. Linux + Windows in sync.

  predate this fix.
- **build(win32):** first working MSVC build of Zero Hour on a remote Windows box (`scripts/remote-build.sh`, ssh alias
  `vadapuppy`). MinGW links but the exe needs the debug `d3dx8d.dll`; the MinGW-incompatible static `d3dx8.lib` rules that route
  out, so MSVC is the Windows toolchain. Needs `-DSAGE_USE_DX8=ON -DRTS_BUILD_OPTION_SAGE_PATCH=OFF` (SAGE_USE_DX8 is undefined by
  default and silently selects the Linux DXVK headers).
- **fix:** MinGW compile fixes (`__int64` typedef guards, `socklen_t`, `<sys/stat.h>` in FTP.cpp).
- **feat(netplay):** `-lanhost` / `-lanjoin` headless LAN harness (`LanNetplayHarness.cpp`) + `tools/netplay/run-netplay.sh`.
  First Linux-host / Windows-join match with two Hard AIs: 9000 frames, state CRCs and final stats identical on both machines.
  LANAPI menu callbacks skip their UI work while the harness runs. Details: `tools/netplay/README.md`.
