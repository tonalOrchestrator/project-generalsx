## 2026-09-30 — AI-vs-AI skirmish runner (`-aiskirmish`) + two engine fixes

- **feat(aiskirmish):** new `Core/GameEngine/Source/Common/AISkirmishSimulation.cpp`. Fills
  `TheSkirmishGameInfo` with AI-only slots (no human slot — the engine's always-present ReplayObserver
  becomes the local player), starts a normal `GAME_SKIRMISH`, and in `-headless` steps the logic until
  `VictoryConditions::getEndFrame()` is set, then prints `AISKIRMISH_RESULT {json}` with per-player
  `ScoreKeeper` totals. Windowed mode runs the normal engine loop with the observer camera hopping between
  AI bases. Flags: `-aiskirmish <map>`, `-aiskirmishSlots`, `-aiskirmishSeed`, `-aiskirmishMaxMinutes`,
  `-aiskirmishStats`, `-aiskirmishCameraSeconds`, `-aiskirmishScreenshotSeconds`. Verified Hard-vs-Hard
  1v1 on North America headless (19 game-min in ~23 s, seed-deterministic) and windowed.
  Design/usage/build notes: `docs/WORKDIR/planning/PLAN-023_AI_SKIRMISH_HARNESS.md`.
- **fix(camera):** screen-edge scrolling ran with a phantom (0,0) cursor when the pointer never entered the
  window (Wayland), dragging the camera into the map corner every frame. `SDL3Mouse::init` now seeds
  cursor-inside from `SDL_GetMouseFocus()`; `LookAtTranslator` skips edge scroll while the cursor is outside.
- **fix(loadscreen):** `MultiPlayerLoadScreen::init` dereferenced the local slot unguarded; null when there is
  no human slot. Headless AI mode also skips the load screen entirely.
- **fix(render):** watch mode was a black window: `Intro::doPostIntro` sets `m_breakTheMovie`, which makes
  `W3DDisplay::draw` skip rendering until the main menu clears it — never happens on the bypassed-shell path.
  Cleared in `AISkirmishSimulation::updateWatchCamera`.
- Known: `-seed` is clobbered by `GameData.ini FixedSeed` after command-line parsing — use `-aiskirmishSeed`.
- Build on Fedora 44: Fedora's `zlib-ng-compat` CMake config collides with vcpkg's zlib during
  `PNGConfig.cmake`'s CONFIG-mode `find_dependency`; worked around with a local `ZLIBConfig.cmake` shim on
  `CMAKE_PREFIX_PATH` (see the plan doc).
